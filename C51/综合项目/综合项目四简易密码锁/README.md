## 元数据

| 项目 | 说明 |
| :--- | :--- |
| 芯片 | AT89C51 / STC89C52 |
| 工具链 | Keil uVision4（C51 / Keil4） |
| 仿真 | Proteus 7.8（`proteus/简易密码锁.DSN`） |
| 晶振 | 以原理图 / 工程为准（常见 11.0592MHz 或 12MHz） |
| 编码 | GBK / ANSI（`c/4.c`） |
| 验证状态 | **已仿真通过**（仓库含 `.DSN`；请按现象自测一次） |
| 预期现象 | LCD1602 显示提示；矩阵键盘输入密码；正确/错误有对应显示；支持进入设置修改密码（以源码逻辑为准） |
| 工程文件 | 仓库只提供源码，请用 Keil4 新建工程后编译 |

## 快速上手

1. Proteus 打开 [`proteus/简易密码锁.DSN`](./proteus/简易密码锁.DSN)  
2. Keil4 **新建** C51 工程，将 [`c/4.c`](./c/4.c) 加入并编译出 `.hex`  
3. 加载到仿真中的单片机模型并运行  
4. 用矩阵键盘输入密码，对照 LCD 显示是否与「预期现象」一致  

## 硬件要点

| 物料 | 说明 |
| :--- | :--- |
| 51 最小系统 | STC/AT89 系列 |
| LCD1602 | 显示输入与结果 |
| 4×4 矩阵键盘 | 数字与功能键 |
| 上拉/限流电阻 | 按原理图 |

> 详细按键定义与密码逻辑见源码注释（文件为 GBK，请用 Keil 或 VS Code 按 GBK 打开）。

## 学习要点

- 矩阵键盘扫描与消抖  
- LCD1602 字符显示与界面状态  
- 密码比较、错误处理、修改密码流程  

## 踩坑提示

- GitHub 网页打开 `.c` 中文注释可能乱码 → 正常，属 GBK；本地用 Keil/VS Code  
- 仿真能编过但无显示 → 先查 LCD 对比度与 RS/EN 接线  
- 键盘某一列无响应 → 查该列上拉与行列线是否接反

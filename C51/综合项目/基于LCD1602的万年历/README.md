## 快速上手

1. Proteus 7.8 打开 [`proteus/基于LCD1602的万年历.DSN`](./proteus/基于LCD1602的万年历.DSN)
2. Keil4 **新建** C51 工程，把 [`c/main.c`](./c/main.c) 加入并编译出 `.hex`
3. 把 `.hex` 加载到仿真里的单片机模型并运行
4. 对照「预期现象」自测：走时是否正常、按键能否隐藏/设置

## 代码要点

- **逐位刷新**：每个显示位用 `last_xxx` 缓存上一次的值，只有变化才重写 LCD，避免整屏刷新闪烁
- **BCD 互转**：DS1302 存的是 BCD 码，读写时间要过 `bcd2dec` / `dec2bcd`
- **设置状态机**：`set_mode` 0=正常 ~ 6=秒，配合 `blink_flag` 让当前设置位闪烁
- **掉电走时**：DS1302 由独立晶振供电走时，仿真里注意给它接 32.768kHz 晶振

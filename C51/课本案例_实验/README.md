## 每个实验的目录结构

```
实验X/
├── 实验X报告.docx        ← 实验报告（含个人信息，未提交）
├── c/                     ← Keil工程
│   ├── main.c             ← 源代码
│   ├── *.uvproj           ← Keil工程文件
│   └── STARTUP.A51        ← 启动文件
└── proteus/               ← Proteus仿真
    └── *.DSN              ← 仿真电路图
```

## 快速上手

1. 新建 Keil 工程（选择 AT89C52 芯片）
2. 将 `c/` 目录下的 `.c` 文件和 `STARTUP.A51` 添加到工程
3. 编译生成 `.hex` 文件
4. 用 Proteus 打开对应电路图，加载 `.hex` 运行仿真

> ⚠️ **编码说明**：源码注释为 **GBK 编码**（Keil uVision5 默认编码），用 VS Code 打开时需手动切换到 GBK 编码，否则中文注释会乱码。

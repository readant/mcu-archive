# 51单片机学习实例库

> ⚠️ **声明**：本目录代码和电路图来源于网络收集资料（51黑论坛、Proteus仿真300例、教材配套光盘等），经整理后重新编写注释，仅供学习参考。如有侵权，请联系删除。

> 💡 **编码说明**：所有 `.c` 文件为 **GBK 编码**，VS Code 打开时会自动切换（项目已配置 `.vscode/settings.json`）。

> 📂 **项目结构**：每个实例包含 `c/`（源码）和 `proteus/`（电路图，如有），只提交 `.c` 文件，不提交 Keil 工程文件。

## 学习路径

```
C语言基础 → LED控制 → 数码管显示 → 按键输入
    ↓
定时器与中断 → 声音与音乐 → LCD液晶显示
    ↓
传感器应用 → AD/DA转换 → 存储器与时钟
    ↓
串口通信 → IO扩展与接口芯片 → 通信协议与总线
    ↓
电机与控制 → 红外遥控 → LED点阵 → 综合应用
```

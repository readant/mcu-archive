## LCD1602引脚说明

| 引脚 | 功能 | 接线 |
|:---|:---|:---|
| RS | 数据/命令选择 | P2^5 |
| RW | 读/写选择 | P2^6 |
| E | 使能信号 | P2^7 |
| D0~D7 | 数据口 | P0 |

## 常见问题

- **LCD不显示**：检查初始化时序、检查背光
- **显示乱码**：检查数据线接线、检查时序
- **中文显示不了**：LCD1602不支持中文，需要LCD12864

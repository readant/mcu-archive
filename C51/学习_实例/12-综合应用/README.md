| 03 | [数字温度计](./03-数字温度计) | DS18B20+LCD1602 | ⭐⭐⭐ |
| 04 | [电子密码锁](./04-电子密码锁) | 矩阵键盘+LCD显示 | ⭐⭐⭐ |
| 05 | [倒计时器](./05-倒计时器) | 倒计时逻辑、报警 | ⭐⭐ |
| 06 | [数字电压表](./06-数字电压表) | ADC+LCD显示 | ⭐⭐⭐ |
| 07 | [电子钟](./07-电子钟) | DS1302+LCD1602+按键调时 | ⭐⭐⭐ |
| 08 | [温度报警器](./08-温度报警器) | 温度采集+阈值报警 | ⭐⭐⭐ |

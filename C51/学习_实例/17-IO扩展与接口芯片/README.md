# 17-IO扩展与接口芯片

> 单片机IO口有限，通过专用芯片扩展IO能力是进阶必学内容。

## 实例列表

| 编号 | 实例名称 | 核心知识点 | 难度 |
|------|---------|-----------|------|
| 01 | 74HC595串入并出控制LED | SPI串行转并行，3线控8路 | ⭐⭐ |
| 02 | 74LS164移位寄存器驱动数码管 | 串入并出，无锁存连续输出 | ⭐⭐ |
| 03 | 8255并行口扩展 | Intel 8255 PPI，可编程IO | ⭐⭐⭐ |
| 04 | 74HC154译码器应用 | 4-16线译码，4线控16路 | ⭐⭐ |
| 05 | 74LS138译码器应用 | 3-8线译码，地址译码基础 | ⭐⭐ |
| 06 | 74LS148扩展中断 | 8-3优先编码，中断扩展 | ⭐⭐⭐ |

## 学习建议

1. **74HC595** - 最常用的IO扩展方案，SPI协议入门，建议第一个学
2. **74LS138/154** - 译码器原理简单，适合理解"少控多"的扩展思想
3. **8255** - Intel经典芯片，理解可编程外设接口的概念
4. **74LS148** - 中断扩展方案，理解优先级编码的概念

## 接线要点

- 74HC595: SER→P1.0, SRCLK→P1.1, RCLK→P1.2, OE→GND
- 74LS164: DSA/DSB→P1.0, CP→P1.1
- 8255: 数据总线→P0, CS/WR/RD/A0A1接控制线
- 74HC154: A0-A3→P1.0-P1.3, E1/E2→P1.4-P1.5
- 74LS138: A0-A2→P1.0-P1.2, G1→P1.3, G2A/G2B→P1.4-P1.5
- 74LS148: 输入→8路中断源, 输出→P2.0-P2.2

## 踩坑记录

| 问题 | 原因 | 解决 |
|------|------|------|
| 74HC595输出乱码 | 时序不对 | 确认数据在SRCLK上升沿采样，RCLK上升沿锁存 |
| 74LS164显示不稳定 | 无锁存功能 | 需持续刷新或改用74HC595 |
| 8255无法读写 | 控制字写入顺序 | 先写控制字，再操作端口 |
| 74LS148优先级反了 | 输出是反码 | 读取后取反使用 |

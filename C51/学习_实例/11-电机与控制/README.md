## 电机类型对比

| 类型 | 控制方式 | 特点 |
|:---|:---|:---|
| 直流电机 | PWM调速、H桥换向 | 简单，适合速度控制 |
| 步进电机 | 脉冲序列驱动 | 精确定位，适合位置控制 |
| 舵机 | PWM脉宽控制角度 | 内置控制电路，角度0~180° |
| 继电器 | 高低电平开关 | 控制大功率设备 |

## 安全提示

- 控制220V设备时务必注意安全
- 电机堵转时电流很大，需要限流保护
- 继电器触点有额定电流，不要超载

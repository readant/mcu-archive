## 学习建议

1. 先做01-静态显示，确认段码表和接线正确
2. 再做02-动态扫描，理解视觉暂留原理
3. 03~04是动态扫描的实际应用
4. 11-消隐技术是动态扫描的重要细节，务必掌握
5. 12-MAX7221是专用驱动芯片方案，简化硬件设计

## 常见问题

- **显示乱码**：检查段码表是共阴极还是共阳极
- **亮度不够**：动态扫描延时太长，减小Delay值
- **鬼影**：扫描时先消隐再刷新（详见实例11）
- **MAX7221不显示**：检查SPI时序和CS片选信号

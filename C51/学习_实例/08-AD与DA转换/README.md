# 08-AD与DA转换

AD（模数转换）把模拟信号变成数字量，DA（数模转换）反过来。

## 关键公式

```
电压 = AD值 × 参考电压 / 分辨率
     = AD值 × 5.0V / 255

DA输出电压 = DA值 × 参考电压 / 255
```

## 常见问题

- **AD值跳动大**：加滤波电容、软件取平均值
- **电压不准**：检查参考电压、检查接线
- **I2C通信失败**：检查上拉电阻（4.7K）、检查时序

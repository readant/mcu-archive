## C51特殊关键字

| 关键字 | 用途 | 示例 |
|:---|:---|:---|
| `sbit` | 定义位变量 | `sbit LED = P1^0;` |
| `sfr` | 定义特殊功能寄存器 | `sfr P1 = 0x90;` |
| `code` | 存储在ROM中 | `unsigned char code tab[] = {0,1};` |
| `bit` | 位变量类型 | `bit flag = 0;` |
| `interrupt` | 中断服务函数 | `void isr() interrupt 1` |
| `using` | 指定寄存器组 | `void isr() interrupt 1 using 1` |

## 学习建议

- 先做05-蜂鸣器（最简单）
- 再做06-人体红外（数字信号，最简单）
- 然后做01/08-温度/温湿度（单总线协议）
- 最后做02/03/04（模拟信号/时序更复杂）

## 常见问题

- **DS18B20不响应**：检查上拉电阻（4.7K）、检查时序
- **DHT11读取失败**：采样间隔要>1秒、检查接线
- **超声波测距不准**：检查温度补偿、避免干扰

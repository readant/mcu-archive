## 核心概念

```
TMOD = 0x01  →  定时器0，模式1（16位）
TMOD = 0x02  →  定时器0，模式2（8位自动重装）
TMOD = 0x10  →  定时器1，模式1

EA = 1       →  开总中断
ET0 = 1      →  开定时器0中断
TR0 = 1      →  启动定时器0
```

## 常见问题

- **中断不响应**：检查EA、ETx、TRx是否都置1
- **定时不准**：检查晶振频率，重新计算初值
- **中断号搞错**：定时器0=中断1，定时器1=中断3，INT0=中断0，INT1=中断2

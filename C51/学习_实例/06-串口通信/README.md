## 波特率计算（11.0592MHz）

| 波特率 | TH1重装值 | 误差 |
|:---|:---|:---|
| 9600 | 0xFD | 0% |
| 4800 | 0xFA | 0% |
| 19200 | 0xF8 | ~0.2% |
| 115200 | 0xFF | ~0.2% |

## 常见问题

- **收不到数据**：检查波特率、检查MAX232接线
- **乱码**：晶振频率与波特率不匹配
- **发送不完整**：等待TI标志再发送下一字节

## 按键消抖原理

机械按键按下时会产生抖动（约5~20ms），需要消抖处理：

```
按下 → 抖动期(5~20ms) → 稳定按下 → 抖动期 → 稳定松开
```

消抖方法：
1. **软件延时**：检测到按下后延时20ms再确认（本例采用）
2. **定时器扫描**：定时器中断中周期性扫描
3. **硬件消抖**：RC电路滤波

## 常见问题

- **按键不响应**：检查接线、确认低电平有效
- **一次按下多次触发**：消抖不够或缺少松手等待
- **矩阵键盘串键**：扫描时要逐行扫描，不能同时拉低多行

## 学习建议

1. **RS485** - 工业现场总线首选，差分信号抗干扰，建议先学半双工
2. **I2C** - 两线总线，速度适中，AT24C02是经典入门器件
3. **SPI** - 全双工高速总线，X5045是多功能集成芯片
4. **多机通信** - 51单片机特有能力，理解地址匹配机制
5. **模拟串口** - 硬件资源不足时的救急方案

## 接线要点

- RS485: MAX485的RO→RXD, DI→TXD, RE/DE→IO口控制方向
- I2C: SCL/SDA需接上拉电阻(4.7K-10K)，注意开漏输出
- SPI: CS/SCK/SI/SO四线，时钟极性/相位要匹配
- 模拟串口: 注意采样时机，在数据位中间采样最准确

## 踩坑记录

| 问题 | 原因 | 解决 |
|------|------|------|
| RS485只能收不能发 | DE/RE方向没切换 | 发送前DE=1,发送完DE=0 |
| I2C读取全0xFF | 读操作时序错误 | 读操作需要重复起始条件 |
| SPI读写不稳定 | 时钟极性不对 | 确认CPOL=0, CPHA=0 |
| 模拟串口乱码 | 延时不准 | 用示波器校准延时，注意中断影响 |

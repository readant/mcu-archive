# LED花样灯

## 功能说明

预定义16种花样模式，通过ROM查表法循环显示。

## 硬件接线

| 引脚 | 连接 |
|:---|:---|
| P1.0 ~ P1.7 | 8个LED（低电平点亮） |

## 代码要点

```c
unsigned char code pattern[] = {
    0xFE, 0xFD, 0xFB, 0xF7,  // 逐个点亮
    0xEF, 0xDF, 0xBF, 0x7F,  // 继续逐个
    0xFF, 0x00,               // 全灭、全亮
    0x55, 0xAA,               // 交替闪烁
    0x0F, 0xF0,               // 高低4位交替
    0xCC, 0x33                // 奇偶位交替
};
```

## 踩坑记录

- `code` 关键字将数据存储在ROM中，节省RAM
- 修改 `pattern` 数组即可自定义花样

# LED按键控制

## 功能说明

按下按键翻转LED状态，实现开关效果。

## 硬件接线

| 引脚 | 连接 |
|:---|:---|
| P2.0 | 按键（接GND，低电平按下） |
| P0.0 | LED（低电平点亮） |

## 代码要点

```c
if (KEY == 0)           // 检测按键按下
{
    Delay(20);         // 消抖延时
    if (KEY == 0)      // 再次确认
    {
        LED = !LED;    // 翻转LED状态
        while (!KEY);  // 等待按键松开
    }
}
```

## 踩坑记录

- 按键消抖是必须的，否则会误触发
- `while (!KEY)` 防止按住不放时反复翻转

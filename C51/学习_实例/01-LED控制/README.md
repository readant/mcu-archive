## 学习建议

1. 先做 01-单灯闪烁，确认硬件没问题
2. 再做 02-03 流水灯，理解移位运算
3. 最后做 06-呼吸灯，理解PWM概念

## 常见问题

- **LED不亮**：检查接线、检查限流电阻、确认低电平点亮
- **流水灯方向反了**：检查初始值和移位方向
- **延时不准确**：与晶振频率有关，12MHz是常见值

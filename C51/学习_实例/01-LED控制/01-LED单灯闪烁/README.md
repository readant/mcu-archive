# LED单灯闪烁

## 功能说明

最基础的51单片机入门程序，控制单个LED以固定频率闪烁。

## 硬件接线

| 引脚 | 连接 |
| :--- | :--- |
| P1.0 | LED正极（通过限流电阻） |
| GND | LED负极 |

> 💡 LED低电平点亮，高电平熄灭

## 代码要点

```c
sbit LED = P1^0;  // 定义P1.0为LED控制引脚

LED = 0;  // 点亮
LED = 1;  // 熄灭
```

## 踩坑记录

- 忘记加限流电阻会烧LED
- `Delay` 函数的延时时间与晶振频率有关，12MHz晶振下约500ms

# LED闪烁交替

## 功能说明

奇偶位、高低位交替闪烁，展示多种花样组合。

## 硬件接线

| 引脚 | 连接 |
|:---|:---|
| P0.0 ~ P0.7 | 8个LED（低电平点亮） |

## 代码要点

```c
P0 = 0xAA;  // 1010 1010，偶数位亮
P0 = 0x55;  // 0101 0101，奇数位亮
P0 = 0xCC;  // 高2低2交替
P0 = 0x33;  // 低2高2交替
P0 = 0x0F;  // 高4灭低4亮
P0 = 0xF0;  // 高4亮低4灭
```

## 踩坑记录

- 本质就是往端口写不同的二进制数
- 可以自由组合任意花样

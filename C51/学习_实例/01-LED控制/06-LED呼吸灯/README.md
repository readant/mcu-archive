# LED呼吸灯

## 功能说明

通过软件PWM实现LED亮度渐变，模拟呼吸效果。

## 硬件接线

| 引脚 | 连接 |
|:---|:---|
| P1.0 | LED正极（通过限流电阻） |

## 代码要点

```c
// 一个PWM周期
LED = 0;                // 点亮
Delay(duty);            // 高电平时间
LED = 1;                // 熄灭
Delay(period - duty);   // 低电平时间

// 调整占空比
duty += step;           // step=5变亮，step=-5变暗
```

## 踩坑记录

- `period` 越小，PWM频率越高，LED越稳定
- `step` 值越小，呼吸效果越平滑
- 实际效果受 `Delay` 精度影响，可用于简单场景

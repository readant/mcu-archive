# Proteus 电路区块库（.SEC）

可复用的 Proteus 导出电路区块（ISIS Section），按功能分类，方便新工程快速拼装。

## 怎么用

1. 打开 Proteus（约定版本 **7.8**）与你的 `.DSN` / `.pdsprj`
2. 菜单 **Design → Import Section…**（或对应版本的「导入区块 / 选择区块」）
3. 从本库对应分类目录选择 `.SEC`，导入后按需要改标号与网络
4. 区块以**本库为唯一存放处**；各工程目录不再保留 `.SEC` 副本，需要时从本库导入即可

> 区块只是电路「积木」，导入后仍需按项目接线，并在 Keil4 中编写对应源码。

## 目录结构

```
proteus_blocks/
├── 01-最小系统/     MCU 最小系统
├── 02-显示/         LCD、数码管等显示
├── 03-输入/         按键、矩阵键盘等输入
└── 04-时钟/         实时时钟等时基电路
```

## 扩展约定

- 新导出的区块请按功能放进对应 `0x-分类/`，命名用**中文功能名**（如 `独立按键.SEC`）
- 在本 README 的清单表中补一行，方便检索
- 同一功能已有区块时优先复用；**不要**在各工程目录再存一份 `.SEC`

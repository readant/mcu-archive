## 这个阶段我做了什么

连单片机长什么样都不知道的时候，老师在讲台上讲寄存器，我在下面想：这玩意儿怎么就控制LED了？

后来发现，**Proteus救了我**。不用买硬件，不用接线，不用怕烧板子——只需要在电脑上搭电路、写代码、点仿真，LED就亮了。

这个阶段不追求多高深，目标很简单：

- 搞懂51单片机的寄存器到底怎么配
- 学会用C语言驱动常见外设
- 能独立完成一个完整的仿真项目

**环境约定**（与根 [README](../README.md#-环境与编码约定) 一致）：**Keil uVision4（Keil4）** · **Proteus 7.8** · 源码 GBK · 请用源码自建工程。选用旧版是为了资源更好传播、兼容各种历史工程。

## 📌 几个踩过的坑

**1. Keil里找不到头文件**
→ 检查 `Target Options → C51 → Include Paths`，路径写错是常事

**2. Proteus仿真不动**
→ 晶振频率设对了吗？单片机型号选对了吗？这两个问题能卡你半天

**3. 代码编译过了但LED不亮**
→ 你可能把P0和P1搞混了。是的，我干过

**4. 数码管显示乱码**
→ 段码表抄错了。一个数字查错，后面全崩

**5. GitHub 上源码注释是乱码**
→ `.c` 为 GBK，属预期；用 Keil 或 VS Code（本仓库已配 encoding）打开

## 💡 这个阶段值什么

有人问：现在都用STM32、ESP32了，学51还有意义吗？

我的回答是：**51是理解底层的最佳入口**。

- 寄存器操作让你理解"硬件和软件是怎么对话的"
- 手动配置每一个位，让你知道"驱动库帮你干了什么"
- 中断、定时器、串口，这些概念在所有MCU上都通用

先学走，再学跑。51就是那双学步鞋。

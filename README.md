## 🧰 环境与编码约定

> 克隆后请先按本表对齐环境。跑不起来时，优先对照本表排查——这些坑我自己都踩过；还不行就开 Issue，把现象发我一起看。  
> **C51/C52 仿真与开发环境统一为：Keil uVision4（Keil4）+ Proteus 7.8**（便于资源传播与版本兼容）。

| 项目 | 约定 | 说明 |
| :--- | :--- | :--- |
| 芯片 | AT89C51 / STC89C52RC | C51 仿真常用 AT89C51；C52 实物为普中板 STC89C52 |
| 工具链 | **Keil uVision4（C51 / Keil4）** | 为方便资源传播与多环境兼容，不采用 uVision5；本仓库只提供源码，请自行新建工程 |
| 仿真 | **Proteus 7.8** | 综合项目 / 实战训练 / 课本实验含 `.DSN`；`学习_实例` 为纯源码。优先用 7.8 打开 |
| 晶振 | 以各项目 README 元数据表为准 | 常见 11.0592MHz 或 12MHz，写错会导致延时/串口波特率偏差 |
| 源码编码 | **C51/C52：GBK（ANSI）** | 中文 Windows + Keil 场景；GitHub 网页可能显示乱码，属预期 |
| 文档编码 | UTF-8 | 所有 `.md` 为 UTF-8 |
| 本地编辑器 | 已提供 `.vscode/settings.json` | VS Code 打开 `.c` 会自动按 GBK 解码 |
| ESP32 阶段 | **UTF-8** | 与 C51 分轨，勿混用 |

> **为什么是 Keil4 + Proteus 7.8？**  
> 教程、例程、论坛资源大量基于这两款旧版环境；它们更易获取，也更能打开各种历史工程/电路，利于学习资源的传播与复用。后续 C51/C52 文档中的工具链约定均以此为准。

### 10 分钟跑通第一颗 LED（推荐入口）

1. 安装 **Keil uVision4** + **Proteus 7.8**  
2. 打开 [C51/学习_实例/01-LED控制/01-LED单灯闪烁](./C51/学习_实例/01-LED控制/01-LED单灯闪烁)  
3. 新建 Keil4 工程（芯片选 AT89C51），把 `c/main.c` 加入工程并编译  
4. 用 Proteus 7.8 搭最小系统 + LED（或直接从综合项目里挑一个现成 `.DSN`），加载生成的 `.hex` 仿真  

> 详细图文见各精选项目 README 的「快速上手」。请用 **Keil4** 按下方步骤自行新建工程后再编译。

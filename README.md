## 为什么做这个仓库

第一次点亮LED的时候，我对着Proteus仿真图傻笑了十分钟。

后来拿到普中开发板，看到真实LED亮起来的那一刻，突然理解了"仿真只是纸上谈兵"这句话。

再后来，用ESP32-S3让一块板子连上WiFi、把温度数据推到云平台上，我发现——这条路值得走下去。

这个仓库不是什么高大上的项目合集。它更像一本日记，记录了我从"这个寄存器怎么配"到"这个传感器怎么接"的全过程。如果恰好也能帮到同样在学单片机的你，那就更好了。

**如果你想看仿真代码和理论推演：**

**如果你想看实物开发：**

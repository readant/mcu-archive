## 🧭 从哪开始？

**我是新手，刚接触单片机** → [C51/](./C51) — 从仿真开始，零成本入门，[156 个可运行实例](./C51/学习_实例) 随便练

**我学过51，想动手做实物** → [C52/](./C52) — 普中开发板，真实硬件体验，从Hello World到万年历

**我想学物联网/WiFi/MQTT** → [ESP32-S3/](./ESP32-S3) — 正点原子ESP32-S3，目前只有环境搭建笔记和路线图

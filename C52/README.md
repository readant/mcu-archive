## 🛠️ 开发环境

### Keil uVision5
- 用于编写和编译C51/C52代码
- 支持C语言和汇编语言

### STC-ISP
- 用于将编译好的hex文件烧录到单片机
- **冷启动技巧**：先点击下载，再给开发板上电

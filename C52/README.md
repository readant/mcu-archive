## 从屏幕到桌面

拿到普中开发板那天，把它摆在桌上看了好久。

芯片是真的，LED是真的，杜邦线是软的，按键按下去有手感——跟Proteus里拖拽元件完全是两种体验。

然后写了第一个程序：

```c
#include <reg52.h>
sbit LED = P1^0;
void main() {
    LED = 0;  // 点亮
    while(1);
}
```

编译，烧录，**灯没亮**。

排查了半小时，发现是杜邦线没插紧。那一刻明白了：**硬件开发，七分靠接线，三分靠代码**。

## 📝 踩坑日记

**坑1：STC-ISP烧录失败**
→ 先点"下载"，再给板子上电。顺序反了就烧不进去。别问为什么，问就是STC的冷启动机制。

**坑2：LCD1602显示方块**
→ 对比度没调。板子上有个蓝色电位器，转一转就清晰了。

**坑3：按键抖动导致数码管乱跳**
→ 加20ms延时消抖。简单粗暴但有效。

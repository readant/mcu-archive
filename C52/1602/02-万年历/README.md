## 功能介绍

- LCD1602第一行显示：`2026-08-18 Mon`（年月日 + 星期）
- LCD1602第二行显示：`12:30:45 25.5C`（时间 + 温度）
- 4个按键设置时间：K1进入/退出设置，K2切换选项，K3加，K4减
- 支持闰年自动修正（2月天数自动判断）
- DS1302掉电走时（电池供电，时间不丢失）
- DS18B20温度采集（状态机非阻塞设计，每5秒更新一次）

1. 用 Keil 打开 `c/wannianli.uvproj` 工程

## 💡 代码亮点

### 1. DS18B20 状态机（非阻塞设计）

```c
// 不用 delay 等待转换完成，而是用状态机分步处理
switch(ds18b20_state) {
    case 0: // 启动转换
        DS18B20_StartConvert();
        ds18b20_state = 1;
        break;
    case 1: // 等待转换完成
        if(ds18b20_wait == 0)
            ds18b20_state = 2;
        break;
    case 2: // 读取温度
        temperature = DS18B20_ReadTemp();
        ds18b20_state = 0;
        break;
}
```

这样设计的好处：温度采集不阻塞主循环，按键响应不会卡顿。

### 2. DS1302 双重校验读取

```c
// 连续读取两次，完全一致才认为数据有效
DS1302_ReadBurst(buf1);
DS1302_ReadBurst(buf2);
for(i = 0; i < 8; i++) {
    if(buf1[i] != buf2[i]) break;
}
if(i == 8) break; // 两次一致，数据有效
```

DS1302在高速读取时可能出错，双重校验保证时间准确。

## 📝 踩坑记录

**坑1：LCD1602显示方块**
→ 对比度没调。板子上有个蓝色电位器，转一转就清晰了。

**坑2：DS1302时间不走**
→ 检查CH位（秒寄存器最高位）。CH=1表示时钟停止，需要写入0才能启动。

**坑3：温度显示负数时乱码**
→ 负数处理逻辑没考虑周全，需要单独处理符号位和绝对值。

**坑4：按键设置时间时LCD闪烁**
→ 设置模式下不应该每次都重写整个显示内容，只更新变化的部分。

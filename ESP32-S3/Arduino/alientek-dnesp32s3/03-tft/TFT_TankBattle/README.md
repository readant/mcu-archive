# TFT 坦克大战

ESP32-S3 + TFT 彩屏 + 红外遥控器的双人像素坦克大战。

- 黄色坦克是你，方向键移动，OK 键开火
- 其他坦克是敌方 AI，会自己下来、随机转向、随机开火
- 被击中掉一条命，3 条命用完 Game Over；打爆敌方坦克 +100 分

## 第一步：测遥控器键值（必做）

打开 `TFT_TankBattle.ino`，把开头的 `TEST_MODE` 改成 `1`，烧录。

打开串口监视器（115200），按遥控器上的 ↑ ↓ ← → 和 OK 键，每个键会打印一行：

```
Key: 0x18233C
```

把每个键对应的十六进制值记下来，填回代码开头：

```cpp
#define KEY_UP     0x18233C   // 改成串口打印的值
#define KEY_DOWN   0x18233D
#define KEY_LEFT   0x18233E
#define KEY_RIGHT  0x18233F
#define KEY_FIRE   0x182334
```

填完把 `TEST_MODE` 改回 `0`，重新烧录，就能玩了。

## 第二步：确认红外接收头引脚

代码里默认 `IR_RECV_PIN = 15`。如果你板子上红外接收头接的不是 GPIO15，改这个数（查正点原子原理图或例程）。

## 引脚

TFT 屏沿用本目录 `TFT_WiFi_Stream` 的配置（DC=7, SCK=18, SDA=16, CS=10），不需要改。

## 依赖库

Arduino IDE 里装两个库：

- **TFT_eSPI**（已经装过）
- **IRremoteESP8266**（库管理器搜 "IRremoteESP8266"）

## 玩法

- 方向键：移动玩家坦克
- OK 键：开火
- 红砖墙可以打掉，别被敌方子弹打中
- 得分刷在屏幕左上角

# ESP32-S3 + OLED 进阶学习路线

> 基线：已跑通 `oled_final`（U8g2 软件 I2C，SCL=GPIO38 / SDA=GPIO39，地址 0x3C，SSD1306 128×64）。
> 原则：做中学，每一级都有可见成果；做完一个再开下一个。

## 0. 先记住这块底板的 I2C 事实

| 总线 | GPIO | 去向 | 用途 |
|---|---|---|---|
| 外部排针 SCL/SDA | 38 / 39 | 底部黄色排针（摄像头扩展口） | 外接 OLED、传感器，**你的 OLED 在这里** |
| 板载主 I2C | 42 / 41 | 板内芯片，未引到该排针 | 板载器件 |

板载主 I2C 实测地址：`0x1E`=AP3216C 光感/接近、`0x20`=XL9555 IO 扩展、`0x50`=24C02 EEPROM、`0x10/0x12`=其他板载器件。
ESP32-S3 有两个 I2C 控制器：OLED 用软件 I2C（任意脚），板载传感器用硬件 `Wire`（41/42），**两条总线可同时工作、互不干扰**。

## 2. 每个案例的标准做法（建议固化成习惯）

1. **先 datasheet，后代码**：搞清楚器件地址、寄存器、数据格式，再动手。
2. **先通信、后功能**：新器件先用 `i2c_scanner` 确认扫到地址，再读 ID 寄存器，最后上业务逻辑。
3. **小步可见**：每写 20 行就让屏幕/串口输出一次中间结果，别一次写完再调。
4. **留笔记**：每个 case 文件夹里加 `NOTE.md`，记录踩的坑和寄存器结论。

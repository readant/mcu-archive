## 为什么是ESP32

51单片机让我理解了什么是"嵌入式"，但让我真正兴奋的，是把一块板子连上WiFi，让手机能远程控制它。

这就是物联网的魅力：**你写的代码，不再只控制一块板子，而是连接了物理世界和数字世界**。

ESP32-S3选它的理由很简单：
- 双核240MHz，性能够用
- 内置WiFi + 蓝牙，不用外接模块
- Arduino IDE / ESP-IDF 双生态
- 正点原子的资料齐全，适合自学

## 🛠️ 环境搭建

### 第一步：安装 Arduino IDE

1. 下载 [Arduino IDE](https://www.arduino.cc/en/software)
2. 打开 `文件 → 首选项`
3. 在"附加开发板管理器网址"中添加：
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
4. 打开 `工具 → 开发板 → 开发板管理器`，搜索 `esp32` 并安装
5. 选择开发板：`ESP32S3 Dev Module`

### 第二步：连接开发板

1. USB线连接正点原子ESP32-S3开发板
2. 打开 `工具 → 端口`，选择对应的COM口
3. 上传一个 Blink 测试程序：

```cpp
#define LED_BUILTIN 48  // 正点原子ESP32-S3板载LED

void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(1000);
    digitalWrite(LED_BUILTIN, LOW);
    delay(1000);
}
```

4. 点击上传，看到板载LED闪烁 = 环境搭建成功 ✅

## 📚 从51到ESP32，思维方式的转变

| | 51单片机 | ESP32-S3 |
|:---|:---|:---|
| 编程模型 | 裸机轮询 | 多任务/RTOS |
| 资源管理 | 手动配置寄存器 | HAL库/驱动框架 |
| 通信方式 | UART串口 | WiFi + MQTT + HTTP |
| 开发节奏 | 编译→烧录→看现象 | 编译→烧录→看串口日志 |
| 调试手段 | 看LED/数码管 | 串口打印 + 逻辑分析仪 |

**核心转变**：从"控制硬件"到"构建系统"。

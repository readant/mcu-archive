## 🔌 板载资源

### ESP32-S3特性
- 双核Xtensa LX7 @ 240MHz
- 512KB SRAM
- WiFi 802.11 b/g/n
- 蓝牙5.0
- 丰富外设（GPIO、ADC、PWM、I2C、SPI等）
